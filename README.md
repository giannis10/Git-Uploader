# Εύκολος Git Ανεβάτστης (Git Easy Uploader)

Αυτό είναι ένα απλό εργαλείο γραφικού περιβάλλοντος (GUI) γραμμένο σε Python με τη χρήση της βιβλιοθήκης `tkinter`. Σκοπός του είναι να απλοποιήσει τις βασικές λειτουργίες του Git, προσφέροντας έναν εύκολο τρόπο διαχείρισης πολλαπλών προφίλ Git και αυτοματοποιώντας την ακολουθία των εντολών.

## Λειτουργίες

Η εφαρμογή παρέχει τα ακόλουθα:

* **Διαχείριση Προφίλ Git:**
    * Προσθήκη, διαγραφή και επιλογή προφίλ (όνομα προφίλ, email, όνομα χρήστη).
    * Αποθήκευση και φόρτωση προφίλ από αρχείο `git_profiles.json`.
    * Προσθήκη πεδίου **"Προεπιλεγμένο Branch"** για κάθε προφίλ (π.χ., `main`, `master`, `develop`), το οποίο συμπληρώνεται αυτόματα στο πεδίο "Τρέχον Branch" της εφαρμογής όταν εφαρμόζεται το προφίλ.
    * Εφαρμογή των στοιχείων του επιλεγμένου προφίλ (email, όνομα χρήστη) **τοπικά** (για το συγκεκριμένο repository) μέσω `git config --local`.

* **Βασικές Λειτουργίες Git (ξεχωριστά κουμπιά):**
    1.  **Αρχικοποίηση Git:** Εκτελεί `git init` στον επιλεγμένο φάκελο του έργου.
    2.  **Προσθήκη Όλων:** Εκτελεί `git add .` για να προσθέσει όλα τα αρχεία στην περιοχή staging.
    3.  **Commit:** Εκτελεί `git commit -m "Μήνυμα"` με το μήνυμα που παρέχεται από τον χρήστη.
    4.  **Push στο Git:** Εκτελεί `git push -u origin [current_branch]` χρησιμοποιώντας το όνομα branch από το πεδίο "Τρέχον Branch".

* **Κουμπί "Εκτέλεση Όλων (Init, Add, Commit, Push)":**
    * Αυτοματοποιεί την πλήρη διαδικασία Git με ένα μόνο κλικ.
    * Εκτελεί με τη σειρά: **Εφαρμογή Προφίλ (εσωτερικά), Αρχικοποίηση Git, Προσθήκη Όλων, Commit, Ορισμός Remote URL, Push στο Git**.
    * Διακόπτεται και εμφανίζει μήνυμα σφάλματος αν κάποιο από τα ενδιάμεσα βήματα αποτύχει.

* **Αυτόματη Ανίχνευση Branch:** Όταν επιλέγετε ένα "Φάκελο Έργου", η εφαρμογή ανιχνεύει αυτόματα το τρέχον branch (`git rev-parse --abbrev-ref HEAD`) και ενημερώνει το πεδίο "Τρέχον Branch".

## Προαπαιτούμενα

Για να λειτουργήσει αυτή η εφαρμογή, πρέπει να έχετε εγκατεστημένα τα εξής στον υπολογιστή σας:

* **Python 3:** Η εφαρμογή είναι γραμμένη σε Python 3.
* **Git:** Το Git Command Line Interface (CLI) πρέπει να είναι εγκατεστημένο και προσβάσιμο από το PATH του συστήματός σας. Η εφαρμογή καλεί απευθείας εντολές Git.

## Εγκατάσταση και Χρήση

1.  **Αποθηκεύστε το αρχείο:**
    Αποθηκεύστε τον κώδικα της εφαρμογής (π.χ., ως `git_uploader.py`) σε έναν φάκελο στον υπολογιστή σας.

2.  **Ρύθμιση Git User Identity (μία φορά):**
    Πριν κάνετε το πρώτο σας commit, το Git απαιτεί να γνωρίζει ποιος είστε. Αν και η εφαρμογή ρυθμίζει τοπικά το email/όνομα, είναι καλό να έχετε και τις global ρυθμίσεις. Ανοίξτε ένα **Terminal** (ή γραμμή εντολών/Command Prompt) και εκτελέστε τις ακόλουθες εντολές, αντικαθιστώντας τα στοιχεία με τα δικά σας:

    ```bash
    git config --global user.email "το-email-σας@example.com"
    git config --global user.name "Το Όνομά σας"
    ```

3.  **Εκτέλεση της εφαρμογής:**
    Ανοίξτε ένα Terminal (ή γραμμή εντολών) και μεταβείτε στον φάκελο όπου αποθηκεύσατε το αρχείο `git_uploader.py`. Στη συνέχεια, εκτελέστε την εφαρμογή:

    ```bash
    python git_uploader.py
    ```

4.  **Οδηγίες εντός εφαρμογής:**

    * **Φάκελος Έργου:** Κάντε κλικ στο "Αναζήτηση" για να επιλέξετε τον βασικό φάκελο του Git project σας. Το πεδίο "Τρέχον Branch" θα ενημερωθεί αυτόματα.
    * **URL Απομακρυσμένου Repo:** Εισάγετε την πλήρη URL του απομακρυσμένου Git repository (π.χ., από GitHub, GitLab, ή τον δικό σας server).
    * **Μήνυμα Commit:** Εισάγετε ένα περιγραφικό μήνυμα για το commit σας.

    * **Διαχείριση Προφίλ Git:**
        * **Προσθήκη νέου προφίλ:** Συμπληρώστε "Όνομα Προφίλ" (π.χ., "GitHub"), "Email", "Όνομα Χρήστη" και το **"Προεπιλεγμένο Branch"** (π.χ., `main` για GitHub, `master` για παλιότερα projects/servers). Πατήστε "Προσθήκη Νέου Προφίλ".
        * **Επιλογή προφίλ:** Επιλέξτε ένα προφίλ από την αναπτυσσόμενη λίστα. Τα πεδία προσθήκης θα συμπληρωθούν για επεξεργασία.
        * **Εφαρμογή Προφίλ:** **Αφού επιλέξετε ένα προφίλ** από τη λίστα, πατήστε το κουμπί **"Εφαρμογή Προφίλ"**. Αυτό θα ορίσει το email και το όνομα χρήστη για **αυτό το συγκεκριμένο repository** και θα συμπληρώσει το πεδίο "Τρέχον Branch" με την προεπιλεγμένη τιμή του προφίλ.

    * **Εκτέλεση Λειτουργιών:**
        * **"Εκτέλεση Όλων (Init, Add, Commit, Push)"**: Συνιστάται για πλήρη αυτοματοποίηση. Βεβαιωθείτε ότι έχετε συμπληρώσει Φάκελο Έργου, Remote URL και έχετε εφαρμόσει ένα Προφίλ.
        * **Μεμονωμένα κουμπιά (1-4):** Πατήστε τα με τη σειρά αν θέλετε να ελέγχετε κάθε βήμα ξεχωριστά.

    * **Έξοδος Κονσόλας:** Παρακολουθήστε την έξοδο στην κάτω κονσόλα για μηνύματα επιτυχίας, προειδοποιήσεις ή σφάλματα.

## Αντιμετώπιση Προβλημάτων

* **"Η εντολή Git δεν βρέθηκε"**: Βεβαιωθείτε ότι το Git είναι εγκατεστημένο και ότι το εκτελέσιμο αρχείο του βρίσκεται στο PATH του συστήματός σας.
* **GUI δεν εμφανίζεται:** Βεβαιωθείτε ότι η εγκατάσταση του Python και του Tkinter είναι σωστή. Δοκιμάστε ένα απλό script Tkinter (`import tkinter as tk; root = tk.Tk(); root.mainloop()`). Αν δεν λειτουργεί, πιθανώς χρειάζεται επανεγκατάσταση του Python (αποφύγετε το Microsoft Store, χρησιμοποιήστε τον επίσημο installer και τσεκάρετε "Add Python to PATH").
* **"Author identity unknown"**: Βεβαιωθείτε ότι έχετε πατήσει "Εφαρμογή Προφίλ" αφού επιλέξετε τον Φάκελο Έργου.
* **"nothing to commit, working tree clean" / "Everything up-to-date"**: Αυτά δεν είναι σφάλματα. Σημαίνουν ότι δεν υπάρχουν νέες αλλαγές στον φάκελο του έργου από το τελευταίο commit/push, οπότε δεν υπάρχει τίποτα να γίνει commit ή να ανέβει.
* **"Updates were rejected because the tip of your current branch is behind..."**: Αυτό σημαίνει ότι το απομακρυσμένο repository έχει νεότερες αλλαγές που δεν έχετε τοπικά. Πρέπει να εκτελέσετε `git pull origin [your_branch]` στο terminal σας για να συγχωνεύσετε τις αλλαγές πριν προσπαθήσετε να κάνετε push ξανά. Η εφαρμογή δεν χειρίζεται αυτόματα τις συγκρούσεις συγχώνευσης (merge conflicts).
* **"fatal: unable to access ... The requested URL returned error: 403"**: Αυτό το σφάλμα προέρχεται από τον απομακρυσμένο Git server (π.χ., GitHub, Gitea). Σημαίνει συνήθως πρόβλημα με τα διαπιστευτήρια (username/password/PAT) ή τα δικαιώματα πρόσβασης στο repository στον server. Βεβαιωθείτε ότι έχετε ρυθμίσει σωστά ένα Personal Access Token (PAT) για το GitHub.
* **"error: src refspec [branch_name] does not match any"**: Σημαίνει ότι το τοπικό σας repository δεν έχει ένα branch με το όνομα που προσπαθείτε να κάνετε push ή το branch δεν έχει κανένα commit ακόμα. Βεβαιωθείτε ότι έχετε κάνει `git init` και το `Commit` πριν το `Push`. Αν θέλετε να αλλάξετε το όνομα του αρχικού branch (`master` ή `main`) σε κάτι άλλο (π.χ. `pi-hole`), πρέπει να εκτελέσετε `git branch -M your-new-branch-name` στο Terminal αφού κάνετε το πρώτο commit.
