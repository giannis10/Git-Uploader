# Εύκολος Git Ανεβάτης (Git Easy Uploader)

Αυτό είναι ένα απλό εργαλείο γραφικού περιβάλλοντος (GUI) γραμμένο σε Python με τη χρήση της βιβλιοθήκης `tkinter`. Σκοπός του είναι να απλοποιήσει τις βασικές λειτουργίες του Git (αρχικοποίηση, προσθήκη αρχείων, commit, ορισμός απομακρυσμένου repository και push) για χρήστες που προτιμούν ένα οπτικό περιβάλλον αντί για τη γραμμή εντολών.

## Λειτουργίες

Η εφαρμογή παρέχει κουμπιά για την εκτέλεση των ακόλουθων Git λειτουργιών με τη σωστή σειρά:

1.  **Αρχικοποίηση Git:** Εκτελεί `git init` στον επιλεγμένο φάκελο του έργου.
2.  **Προσθήκη Όλων:** Εκτελεί `git add .` για να προσθέσει όλα τα αρχεία στην περιοχή staging.
3.  **Commit:** Εκτελεί `git commit -m "Μήνυμα"` με το μήνυμα που παρέχεται από τον χρήστη.
4.  **Ορισμός Remote URL:** Εκτελεί `git remote add origin [URL]` για να συνδέσει το τοπικό repository με το απομακρυσμένο. Αν το `origin` υπάρχει ήδη, το αφαιρεί και το προσθέτει ξανά.
5.  **Push στο Git:** Εκτελεί `git push -u origin [current_branch]` για να ανεβάσει τα commits στον απομακρυσμένο server.

## Προαπαιτούμενα

Για να λειτουργήσει αυτή η εφαρμογή, πρέπει να έχετε εγκατεστημένα τα εξής στον υπολογιστή σας:

* **Git:** Το Git Command Line Interface (CLI) πρέπει να είναι εγκατεστημένο και προσβάσιμο από το PATH του συστήματός σας. Η εφαρμογή καλεί απευθείας εντολές Git. **Δεν απαιτείται εγκατάσταση Python.**

## Εγκατάσταση και Χρήση

1.  **Κατεβάστε το εκτελέσιμο αρχείο:**
    * Κατεβάστε το αρχείο `git_uploader_gr.exe` (ή όπως το έχετε ονομάσει) από την [πηγή λήψης του project σας].
    * Αποθηκεύστε το σε έναν φάκελο στον υπολογιστή σας.

2.  **Ρύθμιση Git User Identity (μία φορά):**
    Πριν κάνετε το πρώτο σας commit, το Git απαιτεί να γνωρίζει ποιος είστε. Ανοίξτε ένα **Terminal** (ή γραμμή εντολών/Command Prompt) και εκτελέστε τις ακόλουθες εντολές, αντικαθιστώντας τα στοιχεία με τα δικά σας:

    ```bash
    git config --global user.email "το-email-σας@example.com"
    git config --global user.name "Το Όνομά σας"
    ```
    Αυτό είναι απαραίτητο μόνο μία φορά ανά υπολογιστή.

3.  **Εκτέλεση της εφαρμογής:**
    Βρείτε το αρχείο `git_uploader_gr.exe` (ή όπως το έχετε ονομάσει) στον φάκελο που το αποθηκεύσατε και **διπλοκλικάρετέ το** για να το εκτελέσετε.

4.  **Οδηγίες εντός εφαρμογής:**
    * **Φάκελος Έργου:** Κάντε κλικ στο "Αναζήτηση" για να επιλέξετε τον βασικό φάκελο του Git project σας.
    * **URL Απομακρυσμένου Repo:** Εισάγετε την πλήρη URL του απομακρυσμένου Git repository (π.χ., από GitHub, GitLab, ή τον δικό σας server).
        * **Για GitHub:** Χρησιμοποιήστε συνήθως την HTTPS URL (π.χ., `https://github.com/your-username/your-repo.git`). Αν το repository είναι ιδιωτικό, ίσως χρειαστεί να χρησιμοποιήσετε [Personal Access Token (PAT)](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens) ως κωδικό πρόσβασης την πρώτη φορά που θα κάνετε push.
    * **Μήνυμα Commit:** Εισάγετε ένα περιγραφικό μήνυμα για το commit σας.
    * **Ακολουθήστε τα βήματα 1-5:** Πατήστε τα κουμπιά με τη σειρά για να εκτελέσετε τις αντίστοιχες Git εντολές.
    * **Έξοδος Κονσόλας:** Παρακολουθήστε την έξοδο στην κάτω κονσόλα για μηνύματα επιτυχίας, προειδοποιήσεις ή σφάλματα.

## Αντιμετώπιση Προβλημάτων

* **"Η εντομή Git δεν βρέθηκε"**: Βεβαιωθείτε ότι το Git είναι εγκατεστημένο και ότι το εκτελέσιμο αρχείο του βρίσκεται στο PATH του συστήματός σας.
* **"Author identity unknown"**: Εκτελέστε τις εντολές `git config --global` που αναφέρονται στην ενότητα "Εγκατάσταση και Χρήση" για να ορίσετε το όνομα και το email σας.
* **"nothing to commit, working tree clean" / "Everything up-to-date"**: Αυτά δεν είναι σφάλματα. Σημαίνουν ότι δεν υπάρχουν νέες αλλαγές στον φάκελο του έργου από το τελευταίο commit/push, οπότε δεν υπάρχει τίποτα να γίνει commit ή να ανέβει.
* **"Updates were rejected because the tip of your current branch is behind..."**: Αυτό σημαίνει ότι το απομακρυσμένο repository έχει νεότερες αλλαγές που δεν έχετε τοπικά. Πρέπει να εκτελέσετε `git pull origin master` (ή `main`) στο terminal σας για να συγχωνεύσετε τις αλλαγές πριν προσπαθήσετε να κάνετε push ξανά. Η εφαρμογή δεν χειρίζεται αυτόματα τις συγκρούσεις συγχώνευσης (merge conflicts).
* **"warning: use of unencrypted HTTP remote URLs is not recommended"**: Αυτό είναι μια προειδοποίηση για την ασφάλεια. Εάν είναι δυνατόν, χρησιμοποιήστε HTTPS URLs (`https://`) αντί για HTTP (`http://`) για μεγαλύτερη ασφάλεια κατά τη μεταφορά δεδομένων.
